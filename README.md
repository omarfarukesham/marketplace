# Alipo Marketplace!

# Technologies

1. Next.js 13 (app router)
2. Tailwind CSS
3. Typescript
4. type

# Folder Structure & Conventions

1. `_directory` means this directory is not a route level directory
   - If a directory is inside a `_directory`, then it is automatically non-route directory
     So no need to add `_` before it.
2. `(directory)` means this directory is not a part of the url, just for grouping directories
3. Following modular folder structure
4. [Read more about directory based routing here](https://nextjs.org/docs/app/building-your-application/routing)

# File Naming conventions

1. All file names are hyphen-separated.
   - Even the components names are hyphen-separated to keep consistent with next.js default names like page.tsx, layout.tsx etc.
